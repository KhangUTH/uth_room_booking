# Thành phần cốt lõi

- `config/`: cấu hình môi trường của ứng dụng.
- `network/`: nơi khởi tạo/cung cấp Supabase client khi tích hợp backend.
- `errors/`: chuẩn hóa lỗi dùng chung.
- `utils/`: tiện ích dùng giữa nhiều tính năng.

Các thư mục hiện được giữ bằng `.gitkeep`; chưa có kết nối Supabase.
Repository nghiệp vụ đặt tại `features/<tính_năng>/data/`.
