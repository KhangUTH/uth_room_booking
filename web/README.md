# Web quản trị UTH

Thư mục dành cho ứng dụng React. Backend dùng chung nằm ở [supabase/](../supabase/README.md).

Mã nguồn web admin nằm ở `admin/`. Vite đọc cấu hình cục bộ từ
`web/.env.local`. Mã tạo tài khoản, SQL vận hành và bài kiểm thử SQL
quản trị nằm trong thư mục Supabase chung ở gốc repo.
