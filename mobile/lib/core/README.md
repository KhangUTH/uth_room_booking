# Hạ tầng dùng chung

Tên route và kiểu dữ liệu truyền giữa màn hình được khai báo trong `router/app_route.dart`. `router/app_router.dart` ánh xạ chúng sang màn hình tương ứng.

Tab dưới do `MainShell` quản lý. Hộp thoại và bảng trượt được mở từ màn hình chứa chúng. Chỉ tạo thêm thư mục hạ tầng khi có mã cần đặt vào đó.
